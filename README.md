# Dhyey Patel Portfolio

Static engineering portfolio built with Astro + Tailwind CSS.

## The one file you edit
All personal content lives in `src/data/portfolio.yaml`.

## Local setup
1. Install Node.js LTS from https://nodejs.org/
2. Open Terminal and move into this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL Astro prints in Terminal.

## Resume
Put your resume PDF at `public/resume.pdf`.

## Before publishing
Replace `https://example.com` in both `astro.config.mjs`, `public/robots.txt`, and the `site.url` field in `src/data/portfolio.yaml` after Vercel gives you your URL.
